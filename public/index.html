Google requires a 16-character App Password (your regular Gmail login password will be rejected by Google's mail server).
1. Visit myaccount.google.com/apppasswords (enable 2-Step Verification if not yet active)
2. Create an App password named IHQA Call Management
3. Copy the 16-letter password, paste it in the SMTP Password box above, click Save Configuration, and click Send Test Email.
